# Class Notes

This folder is for your own notes from the History of Mathematics course.

## Suggested Uses

- Lecture notes on each numeral system (link back to the `20 - Numeral Systems/` notes)
- Problem sets and worked examples
- Reading summaries
- Timeline notes: when was each system used? What were the historical connections?
- Your own observations and questions

## Linking

Use Obsidian `[[wikilinks]]` to connect your class notes to the technical notes. For example:
- A note on the history of Babylonian mathematics can link to [[Babylonian]]
- A note on the development of zero can link to [[Mayan]] and [[Babylonian]]

## Suggested Starting Notes

- `History of Zero.md` — trace zero from Mayan → Babylonian placeholder → Indian → modern
- `Positional vs Additive Systems.md` — compare Egyptian/Roman (additive) to Babylonian/Chinese Rod/Mayan (positional)
- `Greek Numeral Systems Comparison.md` — contrast Attic and Ionian systems, their historical periods
