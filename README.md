# Numeral Translator

A web app that converts Arabic integers into ten ancient numeral systems. Built for MATH315 (History of Math) at Oregon Institute of Technology.

**[Live App →](https://numeral-translator.vercel.app)**

## Supported Systems

Roman · Attic Greek · Ionian Greek · Babylonian · Egyptian · Mayan · Chinese Traditional · Chinese Rod · Glagolitic · Old Church Slavonic

## For Developers

Requirements: Node.js 18+

```bash
git clone https://github.com/EricTalanoa/numeral_translator.git
cd numeral_translator
npm install
npm run dev
```

Run tests: `npm test`
